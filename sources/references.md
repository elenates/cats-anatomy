# References

Scientific references used to verify Latin terms and anatomical facts.
Each fact in `data/*.js` should be traceable to at least one entry below (cited by its ID, e.g. `[NAV]`).

Status:
- **verified** — the source itself was opened and the access details below were checked.
- **planned** — intended for use; not yet opened in this project.
